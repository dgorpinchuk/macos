# Normalize Names — Finder Quick Action

Переименовывает выделенные в Finder файлы и папки **на месте**. Не меняет содержимое, не обходит вложенные каталоги, не требует Word, LibreOffice или сторонних Python-пакетов.

## Правила

- Буквы Unicode (включая кириллицу), цифры и `_` сохраняются.
- Остальные символы, включая пробелы, точки, кавычки, скобки, дефисы и двоеточия, заменяются на `_`.
- Несколько `_` подряд сводятся к одному; `_` по краям убираются.
- Для обычного файла сохраняется последнее расширение (например, `.pdf` или `.docx`); для папки нормализуется всё имя.
- Регистр букв сохраняется. Имена ограничены по длине основной части (не более 170 байт в UTF-8).
- При совпадении имён применяется `_2`, `_3` и т. д.; существующие объекты не перезаписываются.
- Скрытые файлы и папки, начинающиеся с `.`, **пропускаются** (например, `.gitignore`, `.env`). Символические ссылки переименовываются как ссылки, а не их цели.
- Многочастное расширение `archive.tar.gz` станет `archive_tar.gz`: сохраняется только последний суффикс.

Примеры:

| Было | Стало |
| --- | --- |
| `Invoice: ACME (final).pdf` | `Invoice_ACME_final.pdf` |
| `Отчёт 2026.10.31.docx` | `Отчёт_2026_10_31.docx` |
| `Мои файлы (архив)` (папка) | `Мои_файлы_архив` |
| `contract---signed.jpg` | `contract_signed.jpg` |

## Требования

- macOS, Automator, Finder.
- Python 3; проверьте ` /usr/bin/python3 --version `, если используется именно этот путь.

## Установка

1. Скопируйте `normalize_names.py` в `$HOME/scripts/normalize-names/`.
2. Откройте **Automator → New Document → Quick Action**.
3. Установите **Workflow receives current: files or folders**; **in: Finder**.
4. Добавьте действие **Run Shell Script**; Shell — `/bin/zsh`; **Pass input: as arguments**.
5. Вставьте:

   ```zsh
   /usr/bin/python3 "$HOME/scripts/normalize-names/normalize_names.py" "$@"
   ```

   Если Python установлен в другом месте, используйте его полный путь.

6. Сохраните действие как **Normalize Names**.
7. В Finder выделите нужные элементы и запустите **Quick Actions → Normalize Names**.

## Важно

- Операция изменяет имена файлов и папок, поэтому существующие ссылки и пути могут перестать работать. Сначала протестируйте на копиях.
- Вложенные файлы выбранных папок не переименовываются. Если одновременно выделены родительская папка и файл внутри неё, сначала обрабатывается файл, затем папка.
- На case-insensitive томах при конфликте, отличающемся только регистром, имя может получить суффикс. Не запускайте одновременно несколько экземпляров действия над одной и той же папкой.
- Скрипт выводит результаты в stdout/stderr Automator. Он не создаёт новые файлы и не использует рабочую папку.
