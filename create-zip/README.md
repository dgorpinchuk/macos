# Создать совместимый ZIP — Finder Quick Action

Минимальный ZIP для обмена файлами между macOS, Windows и Linux.

## Требования

- macOS и Automator
- Python 3.9+ (`/usr/bin/python3` или другой доступный Python 3)
- Сторонние Python-пакеты не нужны

## Установка

1. Скопируй `create_zip.py` в `~/scripts/create-zip/`.
2. Automator → новый документ **Быстрое действие (Quick Action)**.
3. Получает текущие **файлы или папки** в **Finder**.
4. Действие **Запустить скрипт оболочки**; оболочка `/bin/zsh`; передавать входные данные **как аргументы**.
5. Вставь:

   ```zsh
   /usr/bin/python3 "$HOME/scripts/create-zip/create_zip.py" "$@"
   ```

6. Сохрани как `Создать совместимый ZIP`.

Проверка Python: `/usr/bin/python3 --version`. Если он не установлен, используй путь к своему Python 3.

## Поведение

- Сохраняет ZIP рядом с выделенными объектами; исходники остаются на месте.
- Для одной папки: `ИмяПапки.zip`; для одного файла: `ИмяФайла.zip`; для нескольких объектов: `Archive.zip`.
- При коллизиях создаёт `Archive_2.zip` и т. д.
- По умолчанию ZIP_STORED (уровень сжатия 0). Для быстрого Deflate поменяй `COMPRESSION_LEVEL = 0` на `1`.
- Не включаются `.DS_Store`, `._*`, `__MACOSX`, `.Spotlight-V100`, `.Trashes`, `.fseventsd` и другие служебные объекты из списка в скрипте.
- Обычные скрытые файлы (`.gitignore`, `.env`) **сохраняются**.
- Папки внутри архива сохраняют структуру; вложенные папки обходятся рекурсивно.
- Символические ссылки пропускаются с предупреждением, чтобы не создавать неочевидных или потенциально опасных ссылок на других ОС.
- Файлы должны быть выбраны из одной родительской папки.
- После создания ZIP проходит проверку CRC данных (`testzip`).

## Кодировка имён

Python `zipfile` пишет ASCII имена в обычной ZIP кодировке и ставит UTF-8 flag для имён с не-ASCII символами. Это корректно для современных распаковщиков, но не гарантирует работу со всеми устаревшими ZIP-обработчиками Windows. Для максимальной совместимости со старыми системами нормализуй имена файлов и папок **в ASCII до архивирования**. Обратите внимание: прежний `Normalize Names` сохраняет кириллицу и сам по себе не делает имена ASCII.

## Ограничения

ZIP не сохраняет macOS resource forks, Finder tags и extended attributes; это намеренно для переносимости. UNIX permissions также не следует считать универсально переносимыми в Windows. ZIP64 используется автоматически при больших файлах, но старые архиваторы могут не уметь его читать.
